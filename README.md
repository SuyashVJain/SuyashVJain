## Selected Work

### [Byline](https://github.com/SuyashVJain/byline) - Free LaTeX-style Resume Builder
> A resume builder that never sends your data anywhere.

11 templates, 5 export formats, PDF and DOCX import, resume score, JD match and a readability check. Typst compiles to WebAssembly in the browser, so it works offline, and an end-to-end test checks that nothing leaks over the network (strict CSP).

`TypeScript` `WebAssembly (Typst)` `Playwright` `Offline-first`

### [Codec Git](https://github.com/SuyashVJain/codecgit) - Learn Git in the Browser
> 34 lessons, 6 levels, no install.

An interactive Git course with an in-browser Git simulation (tested with Vitest), a sandbox, quizzes and a cheat sheet. I built it for the sessions I teach to first-year students.

`TypeScript` `Vitest` `Static site` `ESLint + Prettier`

> 100+ downloads. Built, tested and shipped solo.

`Flutter` `Drift` `SQLite` `Android widgets`

### [InboxIQ](https://github.com/SuyashVJain) - Gmail Triage Assistant
> Faster model, slightly less accurate, and I can tell you exactly by how much.

Classifies 5,888 emails into 8 categories. The model I shipped scores 86.8% at 0.12 ms per email, against 87.5% at 1.6 ms for the best alternative: 13x slower for a 0.7-point gain. Streamlit dashboard, Neon backend.

`Python` `scikit-learn` `Streamlit` `Neon`
